# Alex's Caves port audit, 24 October 2026

Scripted audit of both ports (Fabric and NeoForge, Minecraft 26.1.2, v2.0.2-50) against the original Alex's Caves 2.0.2 and the upstream 1.21.1 source. Methods: content inventory diff (jar vs port), method-signature drift against the 26.1.2 jar, re-adding `@Override` in a scratch copy, static mixin check, tag/id/data checks. Nothing was play-tested.

## Verdict

- **Content: complete.** Every block (354), item (238), entity (83), block entity, biome (6), feature, structure (14, 91 templates), sound (481), particle (96), effect, enchantment, advancement (146), recipe (467) and loot table (407) of the original is there, on both loaders. All 995 original classes exist.
- **Behaviour: roughly 85–90 % faithful.** About 60 gameplay hooks still use pre-26.1 method signatures, so they compile but are never called. Fabric additionally lacks a few systems that NeoForge provides natively. Client effects are the weakest area (~75 %).

## Bugs, most severe first

1. **CRASH (NeoForge, GitHub Thiov/alexscaves-fabric#1 and Thiov/alexscaves-neoforge#3)** — `FogRendererMixin` (lines 47, 51, 110, 121) and `LocalPlayerMixin` (30, 31) call `Entity.isEyeInFluid(ACFluidHelper.ACID / PURPLE_SODA)`. Newer NeoForge 26.1.2 builds (e.g. .112) route this through `getFluidTypeByTag()`, which only accepts water/lava and throws `IllegalArgumentException`; the port compiles against .75 where it worked, and the version range allows newer builds. Crashes on world creation / join. Fix: own helper `ACFluidHelper.isEyeInFluid(entity, tag)` reading the fluid state at the eye position (and eye below the surface height); replace the 6 call sites. `EntityFluidTrackingMixin` is a no-op on newer NeoForge for the same reason.
2. **Boss loot doubled (both)** — `LuxtructosaurusEntity:378` and `HullbreakerEntity:212` suppress the vanilla loot table with an empty `dropFromLootTable(DamageSource, boolean)`, but 26.1's method is `dropFromLootTable(ServerLevel, DamageSource, boolean)` (and `spawnAtLocation(ServerLevel, ItemStack)`), so vanilla drops the table AND the custom death sequence drops it again.
3. **Darkness Incarnate flight never ends on natural expiry (Fabric)** — `ACForgeEventMixin:87` injects the removed `LivingEntity.onEffectRemoved` (`require = 0`); replacement `onEffectsRemoved(Collection)`. Flight and 4× fly speed stay; exit sound and Sugar Rush slow-motion end are lost.
4. **~60 dead gameplay hooks (both)** — old signatures, never called:
   - `entityInside` (old 4-arg form): Unrefined Waste (contact irradiation), Primal Magma, Fissure Primal Magma, Muck, Guano, Guano Layer, Nuclear Furnace components.
   - `isInvulnerableTo(DamageSource)` ×14 (should be `isInvulnerableToBase`): Boundroid, Corrodent, Deep One, Gum Worm Segment, Luxtructosaurus, Sauropod, Tremorzilla/Magnetron/Hullbreaker parts, Tripodfish, Underzealot, Submarine, Quarry Smasher — wall/fall/acid immunities lost (gum worm segments can die burrowed).
   - `dropFromLootTable` ×6 (see 2; also Gloomoth, Gingerbread Man (farmable re-drops), Caramel Cube, Ferrouslime loot guards), `dropEquipment()` (Candicorn saddle, Brainiac waste drum, Teletor weapon), `getExperienceReward()` ×5, `causeFallDamage`/`calculateFallDamage` ×~11, `DinosaurEntity.startRiding` (minecart advancement).
   - Blocks: `fallOn` ×3 (dinosaur/Tremorzilla egg trampling, Sundrop), `startOpen/stopOpen` (Metal Barrel, Gingerbarrel, Abyssal Altar), `onRemove` (Magnet ingots, Copper Valve), `isPathfindable` ×10, `propagatesSkylightDown` ×8, `canPlaceLiquid` ×8, `getAnalogOutputSignal` ×2, Ice Cream occlusion, block-entity render bounds ×8 (culling), Magnetron culling box.
   - Client interpolation: `lerpMotion` ×16 (harmless), `lerpTo` ×5 (gum worms, gumballs, peppermints, dagger look choppier).
   - Food: `FoodDataMixin` target gone — Primordial Armor raw-meat bonus dead.
5. **Missing data** — `minecraft:damage_type/no_knockback` tag (radiation, raygun and acid now knock back), `entity_type/undead` (Brainiac) and `enchantment/tooltip_order`; villager/wandering-trader cabin-map trades dead; the 4 pottery sherd patterns aren't registered; polarity armor trim textures likely on the old path. (`magnetic_ruins_4.nbt` is missing upstream too.)
6. **Fabric-only system gaps** — no global loot modifier engine (6 cave tablets + cabin map never appear in vanilla chests; the cabin map can't be obtained at all), AC brewing recipes never registered (5 potions unbrewable), no `FinalizeSpawnEvent` (creepers don't fear raycats, Abyssal drowned get no diving gear), no `LivingChangeTargetEvent` (vallumraptor stealth does nothing), no piston push reaction hook (19 blocks), `MinecartSoundInstanceMixin` not listed in the mixin config, block path-type hooks dead (mobs path over primal magma).
7. **Client stubs (both)** — nuke flash and watcher-possession overlays never draw (gated on removed `RenderSystem.setShaderTexture`), emissive block models are a no-op (ambersol, uranium ore, acidic radrock, abyssmarine, peering coprolith don't glow), Licowitch possession layer and Nucleeper/Gumbeeper energy swirl render nothing, Luxtructosaurus boss bar never drawn, magnetic-attachment rotation, shard/teeth/totem outlines and the dreadbow/possession/submarine FOV tweaks missing; probably the vanilla sky is no longer hidden in cave biomes and ancient leaves don't drop particles.
8. Minor — `ru_ru.json` / `uk_ua.json` contain invalid UTF-8; NeoForge `onVaporize` on the two fluid types is dead.

## Clean

Mixins (all targets exist except the `require = 0` ones above), mixin configs, 4,076 data files parse, all 84 AC tags and referenced ids resolve, no legacy plural folders, renderers/attributes/spawn placements for all entities, all item models/blockstates/sound files present, no client classes leaking into common code, NeoForge enum extensions match.
